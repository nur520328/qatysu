## Алдын ала шешілгені

- Оқушы: тегі, аты, әкесінің аты (міндетті емес). Басқа дербес дерек сақталмайды.
- Сынып атауы: параллель + бас әріп, бос орынсыз (`7В`).
- Оқу тілі сыныпқа жазылады, әдепкі мәні қазақша.
- Excel: әр сынып бөлек парақта; бағандар жобалық құжаттың 2.2-бөлімінде.

## Осы кезеңнің ережелері

- Әр қадамнан кейін: тест, commit, GitHub-қа жүктеу, `工作交付.md` мен `功能地图.md` жаңарту.
- Тек жасанды дерек. Тапсырыс беруші үлгі файл жіберсе, ондағы аты-жөндер ойдан алынған болуы тиіс.
- Excel файлы серверде сақталмайды: оқылады, нәтижесі көрсетіледі, файл өшіріледі.
- Хостингте MariaDB 11.4, әзірлеу ортасында 10.11. 11.4 орнатып көрілді (2026-11-21): жұмыс ортасының желісі MariaDB репозиторийлеріне шығармайды, ал Ubuntu қоймасында тек 10.11 бар. Сондықтан айырмашылық сақталады; шара: әр нұсқа хостингте орнатылғаннан кейін сол жерде тексеріледі.
