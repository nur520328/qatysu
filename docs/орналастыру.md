# Hoster.kz-ке орналастыру

Орта: Plesk панелі, виртуалды хостинг, SSH жоқ. Сайт: `https://qatysu.chemstry.kz`.
PHP 8.4, MariaDB. Дерекқор: `p-337556_qatysu`, пайдаланушысы `p-337556_nur520328`,
хост `localhost:3306`. Пароль еш жерде жазылмайды, ол тек сервердегі `.env` файлында.

Архивті Claude жинайды (`scripts/build-release.sh`) және таза қалтаға ашып тексереді
(`scripts/smoke-release.sh`). Тапсырыс беруші төмендегі қадамдарды панельде жасайды.

Күйі: 1-нұсқа, нақты хостингте әлі сыналмаған. Панельдегі атаулар өзгеше болуы мүмкін;
алғашқы орналастырудан кейін осы құжат нақты атаулармен түзетіледі.

## А. Алғашқы орнату

### 1. Архивті жүктеу
1. Панельде «Сайты и домены» → `qatysu.chemstry.kz` → «Файлы» (файл менеджері).
2. `qatysu.chemstry.kz` қалтасын ашыңыз. Ішінде панель жасаған үлгі файлдар болуы мүмкін
   (`index.html`, `css`, `img` т.б.) — оларды өшіруге болады, платформаға керек емес.
3. «Загрузить» арқылы `qatysu-<нұсқа>.zip` файлын жүктеңіз.
4. Архивті белгілеп, «Извлечь файлы» басыңыз. Файлдар тікелей `qatysu.chemstry.kz`
   қалтасына ашылуы тиіс: ішінде `app`, `public`, `vendor`, `artisan` т.б. көрінеді.
5. Ашылғаннан кейін zip файлын өшіріңіз.

### 2. Сайттың түбір қалтасын көрсету
Сайт `public` ішкі қалтасынан ашылуы тиіс. Қалған файлдар (баптау, код) сырттан көрінбейді.

1. «Сайты и домены» → `qatysu.chemstry.kz` → «Настройки хостинга».
2. «Корневая папка документов» өрісін `qatysu.chemstry.kz/public` етіп өзгертіңіз.
3. PHP нұсқасы 8.3 не одан жоғары екенін тексеріп, сақтаңыз.

### 3. Баптау файлын жасау
1. Файл менеджерінде `.env.example.production` файлын көшіріп, көшірмесін `.env` деп атаңыз.
   (Нүктеден басталатын файлдар көрінбесе, файл менеджерінің баптауынан жасырын файлдарды қосыңыз.)
2. `.env` файлын ашып, `DB_PASSWORD=` жолына дерекқор паролін жазыңыз. Басқа жолдарға тимеңіз.
   Парольде `#` не бос орын болса, оны қос тырнақшаға алыңыз: `DB_PASSWORD="..."`.
3. Сақтаңыз.

### 4. Орнату командасын іске қосу
1. «Сайты и домены» → `qatysu.chemstry.kz` → «Запланированные задачи» → «Добавить задачу».
2. Тапсырма түрі: «Запустить скрипт PHP».
3. Скрипт жолы: `qatysu.chemstry.kz/artisan`
4. Аргументтер: `qatysu:install ЛОГИН` — ЛОГИН орнына әкімшінің логинін жазыңыз
   (латын әріптері мен сандар, мысалы `zavuch`).
5. PHP нұсқасы: 8.4.
6. Кестесі маңызды емес (мысалы, «жылына бір рет»). Тапсырманы сақтап, «Запустить сейчас» басыңыз.
7. Шығысты оқыңыз. Соңында «Орнату сәтті аяқталды» деп тұруы тиіс. «Бір реттік пароль: …»
   жолындағы парольді көшіріп алыңыз: ол бір-ақ рет көрсетіледі.
8. Тапсырманы өшіріңіз (ол енді керек емес; команда қайта іске қосылса да зиян келтірмейді,
   бірақ шығысында пароль қайта көрсетілмейді).

Шығыста «ҚАТЕ:» деген жол болса, ештеңе өзгертілген жоқ: жазылған себепті түзетіп, қайта
іске қосыңыз. Шығысты (парольсіз) Claude-қа жіберіңіз.

### 5. Тексеру
1. `https://qatysu.chemstry.kz` ашыңыз: кіру беті шығуы тиіс.
2. Логин мен бір реттік парольді енгізіңіз → пароль ауыстыру беті → жаңа пароль қойыңыз.
3. Тілді ауыстырып көріңіз, шығып, қайта кіріңіз.
4. Телефон мен планшеттен де ашып көріңіз.

## Ә. Жаңарту (келесі нұсқалар)

1. Панельден дерекқордың сақтық көшірмесін алыңыз («Базы данных» → «Экспортировать дамп»).
2. Жаңа архивті жүктеп, сол қалтаға үстінен ашыңыз. `.env` архивте жоқ, сондықтан ол сақталады.
3. Орнату тапсырмасын аргументсіз (`qatysu:install`) іске қосыңыз: ол кестелерді жаңартады.
4. Сайтты ашып тексеріңіз.

Кері қайтару: алдыңғы нұсқаның архивін үстінен ашып, қажет болса дерекқорды 1-қадамдағы
көшірмеден қалпына келтіру.

## Б. Белгілі шектеулер және тексерілетін нәрселер

| Нәрсе | Күйі |
|---|---|
| Хостингтен `api.telegram.org`-қа шығу | орнату командасының шығысында көрінеді |
| HTTPS артында cookie-дің дұрыс жұмысы | 5-қадамда тексеріледі: кіру жұмыс істесе, дұрыс |
| Жоспарлы жұмыс (cron, минут сайын) | 8-кезеңде қосылады (автоматты есептер үшін) |
| Автоматты сақтық көшірме | 11-кезең |
| HSTS | платформа тұрақты жұмыс істегеннен кейін панельден қосылады |

## В. Ақау болса

| Белгі | Ықтимал себеп |
|---|---|
| Ақ бет не «500» | `.env` жоқ не `storage` қалтасына жазу мүмкін емес; `storage/logs` ішіндегі журналды қараңыз |
| Қалталар тізімі не «403» | түбір қалта `public` етіп көрсетілмеген (2-қадам) |
| Кіру беті ашылады, бірақ дұрыс парольмен кірмейді, қате хабар жоқ | сайт `http://` арқылы ашылған не сервер HTTPS-ті танымай тұр; Claude-қа хабарлаңыз |
| «Дерекқорға қосылу мүмкін болмады» | `.env` ішіндегі пароль қате не тырнақша керек |
